# PCF Post-v0.1 Roadmap

**Status:** NON-AUTHORITATIVE FUTURE CONTEXT  
**Rule:** Nothing in this file may be implemented during v0.1 unless the user explicitly amends `SPEC.md`.

## v0.1 — Prove the cognitive loop

- Today
- frictionless capture
- CognitiveObjects
- twelve-house semantic vectors
- typed relations
- local memory
- contextual Constellation
- one Return/resurfacing card
- one Tension/contradiction card
- ☿ Connect
- ♃ Expand
- ♄ Challenge
- ♂ Act
- deterministic relevance + MMR
- Claude subscription adapter

## v0.1.1 — Navigation amplification

Candidate additions only after v0.1 is validated:

- fast lexical search / Quick Switcher
- date navigation
- peek / hover preview
- Freeze Field
- Parallel Fields
- pinned/frozen contextual working set

## v0.2 — Cognitive interrogation

- local embeddings
- hybrid lexical + semantic retrieval
- stable object references / transclusion
- automatic aliases / unlinked-mention detection
- AI-generated Lenses
- Saved Lenses
- Compare Fields
- belief evolution timeline
- richer source/evidence grounding

## v0.3 — Learning cognition

- personal relevance ranker
- learned curiosity/retrieval policy experiments
- temporal Field comparison
- automatic adjacent-possible discovery
- NotebookLM-style source-grounded research
- periodic synthesis
- richer background cognitive cycle with strict bounds

## Later Vedic layers

Only after the cognitive product proves useful independent of astrology:

- remaining graha operators
- signs as cognitive modes
- strict Jyotish / drishti exploration
- optional natal lens
- optional transit/dasha lens
- longitudinal comparison between symbolic timing and actual cognitive behavior

## Explicitly not on the roadmap by default

- generic plugin marketplace
- template marketplace
- dashboard builder
- generic whiteboard/canvas
- task/calendar suite
- workspace customization system
- folder hierarchy as primary navigation

PCF's design principle remains:

> The user should not have to design the system that helps them think.
